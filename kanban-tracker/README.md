# Kanban Tracker

Desktop-приложение для управления задачами в формате канбан-доски с поддержкой многопользовательской работы через общий сетевой диск.

## Возможности

- Канбан-доска с настраиваемыми колонками
- Карточки с полями: стрим, отдел, ответственные, дата интервью, статус
- Drag-and-drop карточек между колонками
- Автоархивация карточек в колонке "Закрыто"
- Синхронизация между пользователями через общую БД
- Экспорт в Excel/CSV
- Поиск и фильтрация
- Светлая и темная тема
- Portable версия (без установки)

## Технологии

- Electron
- React 18 + TypeScript
- Tailwind CSS
- SQLite (better-sqlite3) с WAL режимом
- @dnd-kit для drag-and-drop
- Zustand для state management

## Разработка

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка Portable EXE

```bash
npm run dist:portable
```

Готовый файл будет в папке `release/`.

## Использование

### Первый запуск

При первом запуске приложения вам будет предложено:

1. **Создать новую базу данных** - выберите папку на сетевом диске
2. **Выбрать существующую базу данных** - подключитесь к БД созданной коллегой

### Совместная работа

Для работы в команде все участники должны:
1. Разместить файл БД на общем сетевом диске
2. Выбрать этот файл в приложении

Изменения синхронизируются автоматически.
